# Pickadoor

Roblox liminal horror game. Two doors, ten seconds, and the one you pick decides your fate for the next trial.

## Toolchain
- [Rokit](https://github.com/rojo-rbx/rokit) manages tools (`rokit.toml`): Rojo, StyLua, Selene. Run `rokit install`.
- Roblox Studio's built-in MCP server is registered for Claude Code in `.mcp.json`.

## Places
| Project file | Place | Contents |
|---|---|---|
| `default.project.json` | Lobby | basement library, queue pads, shop, lanterns, leaderboard |
| `trial.project.json` | Trial | Door Room + PICK A DOOR vote (trial maps come later) |

```
src/shared/         ReplicatedStorage.Shared   Config, Lanterns, Remotes, LanternBuilder, UIKit
src/server-common/  ServerStorage.Common       DataService, Monetization, LanternService
src/lobby/          Lobby scripts + builders/LobbyBuilder (procedural map)
src/trial/          Trial scripts + builders/TrialBuilder
```

## Branding
`assets/branding/` holds placeholder art (icon 512, wordmark, 1920x1080 thumbnail), generated by `python tools/make_logo.py`.

## MCP (agent-driven Studio work)
- Studio: Assistant (top-right icon) > ... > Manage MCP Servers > **Enable Studio as MCP server**.
- `.mcp.json` launches `tools/studio-mcp.cmd`, which finds the newest `StudioMCP.exe` (Roblox's own `mcp.bat` goes stale after updates).
- `python tools/mcp_sync.py [default|trial]` emits Luau that mirrors repo scripts into the open place, for sessions without the Rojo plugin.

## Mesh props (live in the place file, not git)
`ServerStorage.Props` holds Creator Store models (scripts stripped, pivot at bottom centre, `FrontYaw`
attribute). `LobbyBuilder` clones them via `prop()` and falls back to primitive furniture if missing,
so **save the place** after changing props.

## Setting up on another machine
1. Install Roblox Studio and [Rokit](https://github.com/rojo-rbx/rokit), then in the repo run `rokit install` (Rojo, StyLua, Selene). Install the Rojo Studio plugin: `rojo plugin install`.
2. Open `places/Lobby.rbxl` in Studio. It holds what only lives in the place file: the mesh props in `ServerStorage.Props` and the store's wallpaper texture. (The repo's code rebuilds everything else.)
3. Run `rojo serve` in the repo and click Connect in the Rojo plugin, so Studio picks up the latest scripts.
4. In the command bar: `require(game.ServerStorage.Builders.LobbyBuilder).build()` to rebuild the lobby, then save.
5. When you change props in Studio, save and copy the place back to `places/Lobby.rbxl` before committing.

## Develop
1. `rojo build default.project.json -o Lobby.rbxl` and open it in Studio (or open your place and `rojo serve`, then connect with the Rojo plugin).
2. Bake the map into the place: in the command bar run
   `require(game.ServerStorage.Builders.LobbyBuilder).build()`
   (if you skip this, the server builds it on start).
3. Lighting > Technology should be **Future** (scripts can't set it).
4. Press Play. In Studio, teleports are mocked and you get 1000 test Keys when DataStores are unavailable.

## Before going live
- Publish the experience; add a second place for the Trial and publish `trial.project.json` to it.
- Fill in `Config.LobbyPlaceId`, `Config.TrialPlaceId`, `Config.ReviveGamePassId` (`src/shared/Config.luau`).
- Game Settings > Security: enable Studio Access to API Services (DataStores) for testing saves.
